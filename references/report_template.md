# 舆情报告模板（四部分，简短）

标题：中国石化浙江石油负面舆情监控报告（YYYY-MM-DD HH:MM）

## 一、结论

- 等级：红色 / 橙色 / 黄色 / 绿色，一句话写清
- 时间窗口：写起止时间，并注明时间口径
- 红色条数、确认的黄色新增条数；疑似线索和旧闻存档不计入新增，要在结论里说清

## 二、渠道核查表

| 渠道 | 状态 | 检索了哪些内容 | 检索量 | 检索结果 |
| --- | --- | --- | --- | --- |
| 百度、官方、投诉平台 | 已查 / 部分打通 / 未打通 | 主题分组和抽查地市 | 实际可统计的数字；未全量计数的写“未按全量计数”，不编总数 | 无确认新增，或列出确认的负面 |
| 今日头条站内 | 同上 | 6 组关键词，注明筛选条件 | 时间排序遍、相关性遍、去重后三数；被验证挡住的组单独注明 | 同上 |
| 知乎站内 | 同上 | 同上 | 同上 | 同上 |
| 小红书站内 | 同上 | 同上，疑似负面打开详情核对 | 同上，另写打开详情核对的条数 | 同上 |
| 抖音站内 | 同上 | 同上 | 同上 | 同上 |
| 微信公众号 | 同上 | 搜狗微信搜索首批结果 | 同上 | 同上 |

渠道缺口必须如实写：登录墙、滑块验证、相关性排序只核首批、首屏筛查不是穷尽，都要注明。检索量只写一个合计首屏数视为不合格，必须按双通道分开写时间排序遍、相关性遍、去重后三数。

## 三、红色和黄色舆情信息

红色先写，黄色后写；橙色如出现，按等级标注并放在本节，不单独开新节。

### 红色：X 条（没有就写 0 条）

每条一个小节，写清：

- 渠道、链接
- 作者、内容发布时间（按内容发布时间算，不是检索时间）
- 传播情况：点赞、评论、转发、转载数，能看到的写数字，看不到写未显示
- 内容要点和事实状态：已证实 / 媒体报道 / 网友爆料待核实
- 为什么定红色：安全环保事故、人员伤亡、官方立案、停业整顿或上热搜

### 黄色：分两类写

**疑似线索（未坐实，不计入新增）：** 每条写清渠道、链接（没有独立链接的注明“未提取独立链接，不编造”）、作者、内容发布时间、传播情况、内容要点、未坐实点（品牌、站点全称、地点或时间哪一项没确认）。

**已确认归属但属于旧闻的存档（不计入本轮新增）：** 每条写清渠道、链接、作者、内容发布时间、传播情况、内容要点，并注明是旧闻。

## 四、风险排查说明（简短）

- **监控对象：** 中国石化浙江石油分公司及其浙江加油站。浙石化、荣盛、镇海炼化、中石油浙江、绍兴镜湖石油、中石化燃料油销售浙江公司、中石化中原油田、全国“三桶油”讨论，除非正文明确证明属于浙江石油分公司或其站点，否则不计入；无法确认的记待核实。
- **检索方法：** 全部只读，不点赞、不评论、不转发、不发帖。按主题分组查，未逐一穷尽 11 个地市乘以 14 个问题的 150 多个组合。双通道检索：时间排序遍为主、相关性遍为补充，先按发布时间卡窗口，再在窗口内按相关性 / 传播量判级。
- **关键词：** 中国石化 + 浙江 + 地市名称 + 具体问题。地市：杭州、宁波、温州、嘉兴、湖州、绍兴、金华、衢州、舟山、台州、丽水。问题：安全、着火、漏油、服务态度差、燃油宝、洗车、短斤缺两、克扣工资、厕所、客户评价、拖欠款项、加油卡、限量、没油。
- **时间口径：** 一律以舆情内容发布时间为准，不是检索、转载或被看到的时间。只给相对时间的，不换算成确切日期，不硬算进窗口；发布时间卡在窗口边界、无法确认的，记待核实。
- **风险等级：** 红色为安全环保事故、人员伤亡、官方立案、停业整顿或上热搜；橙色为 3 条以上同问题独立投诉、一站集中投诉或地方媒体跟进未回应；黄色为 1 至 2 条孤立投诉、单一来源、未经证实；绿色为窗口内无有效负面。绿色不等于“全网零负面”，只覆盖实际查过的范围。
